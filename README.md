# MedArchive
MedArchive is a modern medical records management platform designed to make healthcare information easier to store, organize, search, and understand.

The application provides a centralized place for users to manage medical records, memories, documents, and health-related information. It uses Supabase for secure backend services, database management, authentication, and data storage, with AI integration to enable intelligent interaction with stored medical information.

Key Features
🏥 Medical Records Management — Store and organize medical information in one place.
🔐 Secure Authentication — User-specific access to personal medical data.
🗄️ Supabase Backend — Database, authentication, and backend infrastructure powered by Supabase.
🤖 AI-Powered Assistance — Interact with medical records using AI.
🔎 Smart Information Access — Quickly find relevant health information and memories.
📋 Centralized Health History — Keep important medical information organized and accessible.
💻 Modern Web Interface — Clean and user-friendly experience for managing records.
